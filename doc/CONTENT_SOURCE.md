# RACINE EYEWEAR — Source éditoriale

Ce fichier résume les sections présentes dans `Textes site vitrine.pdf`.

Le PDF reste la source de référence complète.

## La marque

Titre :
**RACINE - La Culture dans chaque regard**

Le récit explique le parcours de la créatrice :
- découverte de l'univers de l'optique ;
- BTS Opticien-Lunetier ;
- expérience dans les grandes enseignes ;
- volonté de travailler avec des marques originales ;
- Bachelor Lunetier Créateur à Paris ;
- réflexion autour des morphologies de visage ;
- création d'une marque pensée pour différentes morphologies et inspirée par la culture.

## Pourquoi le nom RACINE ?

Le PDF donne cinq dimensions :
1. Les racines comme ancrage, nourriture et connexion.
2. RACINE comme anagramme de Carine.
3. La racine nasale comme élément important en optique.
4. La racine culturelle et la multiculturalité.
5. La racine artisanale liée à Oyonnax et au savoir-faire de la lunetterie française.

## La créatrice

Le récit présente une opticienne devenue créatrice et son envie de créer des lunettes avec une identité.

RACINE fait dialoguer :
- optique ;
- mode ;
- culture ;
- design ;
- savoir-faire artisanal.

## Fabrication et matériaux

La matière principale présentée est l'acétate de cellulose.

Le PDF décrit notamment :
- matière biosourcée ;
- fibre de coton et pulpe de bois ;
- souplesse ;
- résistance ;
- légèreté ;
- confort ;
- couleurs profondes ;
- textures uniques.

Le modèle de production décrit :
- fabrication à la commande ;
- pas de stock ;
- fabrication Made in France ;
- matériaux et verres français et/ou européens ;
- étuis faits main avec une matière recyclée ;
- réutilisation des chutes d'acétate.

## Morphologies

Le document présente des tendances concernant :
- base africaine ;
- base asiatique ;
- base caucasienne.

Point important du texte :
il ne s'agit pas de règles fixes ni de vérités absolues.

La philosophie exprimée est que RACINE cherche à élargir la norme plutôt qu'à exclure.

## Human Book

Le Human Book montre RACINE en mouvement sur différents visages et avec différentes expressions.

Idée centrale :
une monture existe pleinement à travers la personne qui la porte.
